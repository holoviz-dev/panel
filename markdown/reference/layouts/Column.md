# Column

:class: tip

`pn.ui.Column` supersedes `pn.layout.Column`, which remains available and is documented in the [classic Column reference](../classic/layouts/Column.md).
:::

The `Column` layout arranges its contents vertically.

Use `pn.ui.Column` to create this component.
