# Row

:class: tip

`pn.ui.Row` supersedes `pn.layout.Row`, which remains available and is documented in the [classic Row reference](../classic/layouts/Row.md).
:::

The `Row` layout arranges its contents horizontally.

Use `pn.ui.Row` to create this component.
