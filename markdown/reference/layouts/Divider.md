# Divider

:class: tip

`pn.ui.Divider` supersedes `pn.layout.Divider`, which remains available and is documented in the [classic Divider reference](../classic/layouts/Divider.md).
:::

A `Divider` draws a horizontal rule (a `<hr>` tag in HTML) to separate multiple components in a layout.

Use `pn.ui.Divider` to create this component.
