# ArrayInput

:class: tip

`pn.ui.ArrayInput` supersedes `pn.widgets.ArrayInput`, which remains available and is documented in the [classic ArrayInput reference](../classic/widgets/ArrayInput.md).
:::

Edit NumPy arrays as text, disabling editing above ``max_array_size``.

Use `pn.ui.ArrayInput` to create this component.
