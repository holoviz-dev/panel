# ToggleGroup

:class: tip

`pn.ui.ToggleGroup` supersedes `pn.widgets.ToggleGroup`, which remains available and is documented in the [classic ToggleGroup reference](../classic/widgets/ToggleGroup.md).
:::

A factory of Material toggle groups, a group of widgets which can be switched on or off.

Use `pn.ui.ToggleGroup` to create this component.
