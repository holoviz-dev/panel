# DatetimeInput

:class: tip

`pn.ui.DatetimeInput` supersedes `pn.widgets.DatetimeInput`, which remains available and is documented in the [classic DatetimeInput reference](../classic/widgets/DatetimeInput.md).
:::

The `DatetimeInput` allows entering a datetime value using a text input box.

Use `pn.ui.DatetimeInput` to create this component.
